# frontend

Static viewer for inst2vec clustering, deployed to GitHub Pages.

## Stack

Bun · Vite · React 19 · TypeScript · Pixi v8 · jotai · Tailwind.

## Local development

```bash
bun install
bun run dev
```

The dev server reads data from `public/data/`, which is committed to
the repo. Data is generated by `scripts/publish_visualization.py` (run
after clustering finishes).

## Quality gates

```bash
bun run typecheck   # tsc --noEmit
bun run lint        # eslint
bun run test        # vitest (core/ pure modules)
bun run build       # vite build
```

CI runs all four on every push to `frontend/**` and deploys the build
artefact to GitHub Pages.

## Layout

The codebase is layered: `core` → `data` → `state` → `render` /
`interaction` → `ui` → `features` → `app`. Imports flow strictly
downward.
